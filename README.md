# Чистовик

Интерфейс платформы для изучения английского языка: программа занятий, задания, словарные тренажёры и кабинеты ученика и преподавателя.

## Запуск

Нужны Node.js 20.19+ или 22.12+ и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для сборки и локального просмотра результата:

```bash
npm run build
npm run preview
```

Проверка типов: `npx tsc --noEmit`.

## Структура

- `src/components/` — компоненты главной страницы.
- `src/views/` — экран входа и разделы кабинета.
- `src/data/` — встроенные уроки, словари и демонстрационные данные.
- `src/assets/` — изображения.
- `server/index.mjs` — отдельный файл API; см. ограничения ниже.
- `server/data/` — имеющиеся файл данных и ключ подписи.

## Ограничения

Текущий интерфейс хранит учётные данные и данные работы в `localStorage` браузера. Они не синхронизируются между устройствами; очистка данных браузера может их удалить. Вход и хранение паролей в браузере предназначены только для демонстрации, не для работы с реальными учениками.

Файл API `server/index.mjs` присутствует, но интерфейс с ним не связан, а зависимости сервера и команды его запуска в `package.json` отсутствуют. Серверную часть необходимо отдельно восстановить и проверить перед использованием. Не следует считать её готовой к развёртыванию.

Шрифты подключаются с Google Fonts и при отсутствии сети заменяются резервными. Сборка интерфейса создаёт один HTML-файл в `dist/`.

В репозитории также есть `server/data/secret.txt` и `server/data/db.json`: перед публикацией проверьте их содержимое на наличие конфиденциальных данных. Если ключ или пароль уже опубликован, замените его; простое удаление файла не удаляет его из истории Git.

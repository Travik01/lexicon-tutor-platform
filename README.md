# Чистовик — как запустить

Проект = React + Vite + Tailwind (фронтенд) **и** Node/Express API (бэкенд).
Данные учителя (задания, варианты, наборы слов, результаты учеников) хранятся на сервере,
поэтому их видят **все ученики на любом устройстве**.

## Быстрый старт

```bash
npm install
npm run dev:all          # API на :8787 + фронтенд на :5173
```

Отдельно:

```bash
npm run server           # только API      → http://localhost:8787
npm run dev              # только фронтенд → http://localhost:5173 (проксирует /api и /media на :8787)
npm run build && npm start   # прод: API + собранный сайт на одном порту 8787
```

## Вход

| Роль | Как войти | Пароль |
| --- | --- | --- |
| Преподаватель (один на весь сайт) | `admin@chistovik.app` | `english2026` |
| Ученик | вкладка «Ученик» на экране входа | гостевой вход — без пароля; аккаунт — почта + пароль |

Пароль учителя меняется переменной окружения при запуске API:

```bash
TEACHER_PASSWORD="новый-пароль" node server/index.mjs
```

## Что умеет бэкенд (`server/index.mjs`)

Файл базы: `server/data/db.json` (создаётся автоматически, при первом запуске
заполняется демо-заданием и демо-набором слов).
Загруженные mp3/картинки: `server/data/uploads/`, отдаются по `/media/<файл>`.

| Метод | Путь | Кто | Что делает |
| --- | --- | --- | --- |
| GET | `/api/health` | все | проверка живости |
| POST | `/api/auth/login` | все | вход учителя по паролю, ученика-гостя по имени или ученика по `{ email, password }` → токен |
| POST | `/api/auth/student` | все | регистрация аккаунта ученика (имя, почта, пароль; пароль хешируется scrypt) |
| GET | `/api/tasks` | все | библиотека заданий (в том числе одиночные, без варианта) |
| GET | `/api/content` | все | всё, что создал учитель: задания, варианты, наборы, программа курса, комментарии |
| GET | `/api/tests/code/:code` | все | найти вариант по коду с лендинга (без входа) |
| POST/PUT/DELETE | `/api/tasks[/:id]` | учитель | библиотека заданий |
| GET/POST/PUT/DELETE | `/api/tests[/:id]` | учитель | варианты (объединение заданий) |
| PATCH | `/api/tests/:id/status` | учитель | активно / завершено |
| GET/POST/PUT/DELETE | `/api/sets[/:id]` | учитель | наборы слов |
| PUT | `/api/lesson-comments/:lessonId` | учитель | комментарий к встроенному заданию |
| POST | `/api/upload` | учитель | загрузка mp3 / картинки (multipart, до 25 МБ) |
| POST | `/api/submissions` | ученик | результат прохождения (баллы считает сервер) |
| GET | `/api/submissions` | все | ученик — свои, учитель — все |
| PATCH | `/api/submissions/:id` | учитель | проверка развёрнутого ответа: баллы + комментарий |
| GET | `/api/students` | учитель | ученики + их результаты |
| POST | `/api/auth/teacher` | учитель | задать/сменить свой пароль (scrypt-хеш на сервере) |
| PUT | `/api/program` | учитель | сохранить программу курса (сеты/модули/уроки) — видна всем |
| GET | `/api/backup` | учитель | резервная копия базы (JSON-файл) |
| POST | `/api/restore` | учитель | восстановление из резервной копии |

Токен передаётся заголовком `Authorization: Bearer <token>`.
Учительские методы защищены: ученик получит `403`.

## Структура

```
server/index.mjs          API + раздача собранного сайта
src/api/client.ts         клиент API
src/api/useContentStore.ts  единое хранилище контента (сервер + локальный кеш)
src/data/content.ts       типы заданий/вариантов/наборов
src/views/app/ContentHub.tsx     раздел «Контент»: задания и наборы слов
src/views/app/TestBuilder.tsx    конструктор задания/варианта
src/views/app/TaskCardEditor.tsx редактор задания (типы, mp3, объяснения, формат «Трио», таймер)
src/views/app/TestPlayer.tsx     прохождение варианта учеником
src/views/app/SetBuilder.tsx     конструктор набора слов
src/views/app/LexisLab.tsx       тренажёры по словам (карточки, квиз, memory…)
src/views/app/GradingQueue.tsx   проверка развёрнутых ответов учителем
src/views/app/StudentFeedback.tsx блок «Слово преподавателя» у ученика
src/legacy/               старые CreateTask/AssignmentsHub/VocabBuilder (не используются)
```

## Ограничения текущей версии

- База — JSON-файл: удобно для одного учителя и нескольких десятков учеников.
  При росте нагрузки достаточно заменить слой `loadDb/saveDb` на Postgres/SQLite.
- Гостевой вход работает по имени без пароля. Для доступа на другом устройстве ученик может создать аккаунт: пароль хранится на сервере только в виде scrypt-хеша.
- Шрифты (Unbounded, Manrope) лежат локально в `src/assets/fonts` — сайт не
  зависит от Google Fonts и работает офлайн.
- Если API недоступен (`npm run dev` без `npm run server`), интерфейс работает
  из локального кеша, но созданные задания сохранятся только в этом браузере.

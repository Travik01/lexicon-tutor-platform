## Архитектура
- `server/index.mjs` — Express API, JSON-база, загрузка mp3/картинок, токены, статика.
- `src/lib/storage.ts` — безопасное хранилище (localStorage → память), флаг `isPersistent`.
- `src/api/` — клиент + хранилище контента (сервер как источник правды, кеш на случай офлайна).
- `src/views/app/ContentHub.tsx` — «Контент»: задания и наборы слов.
- `src/views/app/TaskBuilder.tsx` — создание одного задания: выбор типа → форма под тип.
- `src/views/app/TestBuilder.tsx` + `TaskCardEditor.tsx` — конструктор варианта из заданий.
- `src/views/app/ProgramView.tsx` — программа курса: сеты по месяцам, модули, уроки (пишет учитель, видят все).
- `src/views/app/TestPlayer.tsx` — прохождение с объяснениями после каждого ответа.
- `src/views/app/SetBuilder.tsx` — конструктор набора слов (таблица + быстрый ввод).
- `src/views/app/GradingQueue.tsx` — проверка развёрнутых ответов.
- `src/views/app/StudentFeedback.tsx` — комментарии преподавателя у ученика.
- `src/assets/mascot-*.png` — новые Эжи и Оли.
- `src/legacy/` — старые CreateTask / AssignmentsHub / VocabBuilder (не подключены).

## Демо-данные
При первом запуске база сама создаёт: вариант «Present Perfect — тренировка»
(3 задания разных типов, код `TASK-101`) и набор слов «Unit 5 — Travelling».
Удаляются кнопкой в интерфейсе или очисткой `server/data/db.json`.

## Ограничения
- Хранилище — JSON-файл (один учитель, десятки учеников). Для масштабирования
  меняется только слой `loadDb/saveDb`.
- Гость входит по имени, без пароля; аккаунт ученика — по почте и паролю,
  хеш хранится на сервере. Учитель — по паролю.
- Без запущенного API фронтенд работает из локального кеша (изменения видны
  только в этом браузере).
